# 🃏 Лендинг сайта "Таролог Елена"

> Одностраничный лендинг для таролога-психолога Елены с интегративным подходом к самопознанию и духовному росту.

## 🎯 Цель проекта

Создать эффективный лендинг, который:
- Привлекает целевую аудиторию (женщины 25-45 лет)
- Строит доверие через профессионализм и теплоту
- Мотивирует к действию через мессенджеры
- Демонстрирует уникальный интегративный подход

## 🚀 Реализованные особенности

### Визуальный стиль
- **Теплый минимализм**: Теплый коричневый фон с золотыми и зелеными акцентами
- **Элегантность**: Сочетание роскоши и духовности
- **Атмосферность**: Изображения карт Таро в фоне Hero секции

### Структура сайта
- **Hero секция**: Эмоциональный хук с фоном карт Таро и прямые CTA
- **Услуги**: 5 основных направлений работы с золотыми акцентами
- **О себе**: Личная история и экспертиза
- **Процесс**: Прозрачность сотрудничества
- **Отзывы**: Социальное доказательство
- **FAQ**: Преодоление возражений
- **Контакты**: Кнопки мессенджеров вместо формы

### Технические решения
- **Оптимизированные изображения**: Все изображения в WebP формате
- **Mobile-first**: Полная адаптивность без горизонтальной прокрутки
- **SEO-оптимизация**: Семантика и мета-теги
- **Производительность**: Vanilla HTML/CSS/JS без тяжелых фреймворков

### 📝 CONTENT.md - Управление контентом

**Новое!** Все тексты на сайте централизованы в файле `CONTENT.md`:
- **Single Source of Truth** - единый источник всех текстов
- Полная карта контента с указанием расположения в HTML
- Связи между контентом и CSS классами
- Инструкции по редактированию
- Быстрый поиск по ключевым словам

**Как использовать:**
1. Откройте `CONTENT.md` (полная документация) или `CONTENT-REFERENCE.md` (быстрая таблица)
2. Найдите нужный текст по структуре
3. Отредактируйте текст
4. Обновите соответствующую строку в `index.html`
5. Проверьте результат в браузере

**Файлы для работы с контентом:**
- `CONTENT.md` - Детальная документация всего контента
- `CONTENT-REFERENCE.md` - Быстрая референс-таблица для поиска
